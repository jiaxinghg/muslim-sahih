# muslim-sahih — 《穆斯林圣训实录全集》知识技能

将《穆斯林圣训实录全集》（Sahih Muslim 中文全译本，穆萨·余崇仁译，伊斯兰之窗版）整理为可供 AI 检索引用的结构化知识库。共 57 章，覆盖伊斯兰教信仰、功修、社会、刑律、后世等全部主题。

## 结构

```
muslim-sahih/
├── SKILL.md          # 技能入口：核心框架总纲 + 57 章索引 + 主题索引
├── chapters/         # 57 个章节文件（参考级摘要）
│   ├── ch01-faith.md
│   ├── ch02-purification.md
│   └── ...
├── glossary.md       # 中阿术语表（约 60 条）
├── patterns.md       # 13 个教法制度模式
├── cheatsheet.md     # 断法决策速查表
└── README.md
```

## 使用方式

- **无参数** — 加载核心框架供参考
- **带主题**（如「天课」「旦札里」「聘礼」）— 读取相关章节后回答
- **带章节**（如「ch09」）— 加载对应章节
- **浏览** — 「有哪些章节?」查看索引

## 内容约定

- 圣训以 `[N]` 引用于章内，编号**每章从 1 起**（如 ch04 [12]），引用须附章号
- 章首 `[译者按]` 为译者按语
- 术语保留译著原词（安拉 / 穆圣 / 伊玛尼 / 主麻 / 哲纳兹 / 卡非尔 / 齐克尔）
